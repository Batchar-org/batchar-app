# JPA → Postgres 스키마 매핑

> Phase 0 산출물 2/5
> Phase 2에서 이 문서를 기반으로 마이그레이션 SQL 작성

---

## 0. 핵심 결정 사항

### 0.1 User ID 타입 변경 (Long → UUID)
batchar-api는 `users.id BIGINT`. Supabase Auth는 `auth.users.id UUID`.
→ **`public.users.id`를 UUID로 변경하고 `auth.users(id)`에 FK**.
모든 FK(`bidder_id`, `seller_id`, `winner_id`, `buyer_id`, `sender_id`, `user_id`)도 **UUID**.

JWT subject 처리도 사용자 ID 비교 로직 전면 변경 (앱 측 영향).

### 0.2 다른 PK는 bigserial 유지
products, bids, wishes, chat_rooms, chat_messages, product_media — `BIGINT GENERATED BY DEFAULT AS IDENTITY`.

### 0.3 Enum 처리
Postgres CREATE TYPE으로 명시적 enum.
- `product_status`: ON_SALE, ENDED, FAILED, CANCELED, TRADED
- `product_media_type`: IMAGE, VIDEO
- `bid_status`: ACTIVE, WON
- `chat_status`: ACTIVE, CLOSED

### 0.4 BaseEntity (created_at / updated_at)
- `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
- `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`
- 모든 테이블에 `BEFORE UPDATE` trigger로 `updated_at = now()` 자동 갱신

### 0.5 Redis 대체 테이블
- `email_verifications` — 이메일 인증 코드 (5분) + verified 플래그(10분) 통합
- Refresh Token: **Supabase Auth가 처리** → 별도 테이블 불필요
- 경매 TTL Redis 키: **불필요** (pg_cron + end_time 컬럼 기반 폴링으로 대체)

## 2. updated_at 자동 갱신 함수 + trigger 패턴

```sql
CREATE OR REPLACE FUNCTION public.set_updated_at()
RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END $$;
```

각 테이블마다:
```sql
CREATE TRIGGER trg_<table>_updated_at
BEFORE UPDATE ON public.<table>
FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
```

## 3. 테이블 매핑

### 3.1 `public.users`

| JPA 컬럼 | Postgres | 변경 |
|---|---|---|
| id (Long, IDENTITY) | id UUID PK | **타입 변경 + auth.users FK** |
| email (UNIQUE, NOT NULL) | email TEXT UNIQUE NOT NULL | (Supabase Auth가 메인이지만 미러링) |
| password (NOT NULL) | — | **제거** (Supabase Auth가 보유) |
| name (UNIQUE, NOT NULL) | name TEXT UNIQUE NOT NULL | |
| address (NOT NULL) | address TEXT NOT NULL | |
| profile_image_url (nullable) | profile_image_url TEXT | |
| created_at | created_at TIMESTAMPTZ NOT NULL DEFAULT now() | |
| updated_at | updated_at TIMESTAMPTZ NOT NULL DEFAULT now() | |

```sql
CREATE TABLE public.users (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email TEXT UNIQUE NOT NULL,
  name TEXT UNIQUE NOT NULL,
  address TEXT NOT NULL,
  profile_image_url TEXT,
  withdrawn_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_users_name ON public.users(name);
```

**탈퇴 처리**:
- JPA `withdraw()`는 placeholder 문자열 갱신 → Postgres에서도 동일 UPDATE
- `withdrawn_at` 컬럼 추가 (탈퇴 시각 기록, 신규 컬럼) — 통계/감사용
- 단, `auth.users` 측 비밀번호 처리: `auth.users` row 삭제 또는 잠금 (Edge Function에서 admin API)

### 3.2 `public.products`

```sql
CREATE TABLE public.products (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  seller_id UUID NOT NULL REFERENCES public.users(id) ON DELETE RESTRICT,
  winner_id UUID REFERENCES public.users(id) ON DELETE SET NULL,
  title TEXT NOT NULL,
  description TEXT NOT NULL,
  category TEXT NOT NULL,
  start_price BIGINT NOT NULL,
  current_price BIGINT NOT NULL,
  status product_status NOT NULL DEFAULT 'ON_SALE',
  start_time TIMESTAMPTZ NOT NULL DEFAULT now(),
  end_time TIMESTAMPTZ NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_products_status_end_time ON public.products(status, end_time);
CREATE INDEX idx_products_seller_id ON public.products(seller_id);
CREATE INDEX idx_products_category_status ON public.products(category, status);
CREATE INDEX idx_products_created_at ON public.products(created_at DESC);
-- 키워드 검색 가속(선택): pg_trgm
-- CREATE EXTENSION IF NOT EXISTS pg_trgm;
-- CREATE INDEX idx_products_title_trgm ON public.products USING gin (title gin_trgm_ops);
```

**JPA 검증 메서드 → SQL 식**
- `isOnSale()` = `status = 'ON_SALE' AND end_time > now()`
- `isValidBidPrice(p)` = `current_price < p`
- `isSeller(uid)` = `seller_id = uid`
- `isClosed()` = `status <> 'ON_SALE'`

```sql

  DELETE FROM public.email_verifications

```

## 4. 핵심 비즈니스 함수 (plpgsql)

### 4.1 `place_bid(p_product_id, p_price)` — 입찰 원자성

```sql
CREATE OR REPLACE FUNCTION public.place_bid(p_product_id BIGINT, p_price BIGINT)
RETURNS public.bids
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_uid UUID := auth.uid();
  v_product public.products;
  v_bid public.bids;
BEGIN
  IF v_uid IS NULL THEN
    RAISE EXCEPTION 'UNAUTHORIZED' USING ERRCODE = '28000';
  END IF;

  SELECT * INTO v_product FROM public.products
    WHERE id = p_product_id FOR UPDATE;

  IF NOT FOUND THEN
    RAISE EXCEPTION 'PRODUCT_NOT_FOUND' USING ERRCODE = 'P0002';
  END IF;

  IF v_product.seller_id = v_uid THEN
    RAISE EXCEPTION 'SELF_BID_NOT_ALLOWED' USING ERRCODE = '42501';
  END IF;

  IF v_product.status <> 'ON_SALE' OR v_product.end_time <= now() THEN
    RAISE EXCEPTION 'AUCTION_CLOSED' USING ERRCODE = '22000';
  END IF;

  IF v_product.current_price >= p_price THEN
    RAISE EXCEPTION 'INVALID_BID_PRICE' USING ERRCODE = '22000';
  END IF;

  UPDATE public.products SET current_price = p_price WHERE id = p_product_id;

  INSERT INTO public.bids (product_id, bidder_id, price, status)
  VALUES (p_product_id, v_uid, p_price, 'ACTIVE')
  RETURNING * INTO v_bid;

  RETURN v_bid;
END $$;

GRANT EXECUTE ON FUNCTION public.place_bid(BIGINT, BIGINT) TO authenticated;
```

### 4.2 `close_auction(p_product_id)` — 경매 마감

```sql
CREATE OR REPLACE FUNCTION public.close_auction(p_product_id BIGINT)
RETURNS VOID
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_product public.products;
  v_top_bid public.bids;
BEGIN
  SELECT * INTO v_product FROM public.products
    WHERE id = p_product_id FOR UPDATE;
  IF NOT FOUND OR v_product.status <> 'ON_SALE' THEN
    RETURN;
  END IF;

  SELECT * INTO v_top_bid FROM public.bids
    WHERE product_id = p_product_id
    ORDER BY price DESC, id ASC
    LIMIT 1;

  IF v_top_bid.id IS NULL THEN
    UPDATE public.products SET status = 'FAILED' WHERE id = p_product_id;
    RETURN;
  END IF;

  UPDATE public.products
    SET status = 'ENDED', winner_id = v_top_bid.bidder_id
    WHERE id = p_product_id;
  UPDATE public.bids SET status = 'WON' WHERE id = v_top_bid.id;

  -- 채팅방 자동 생성
  INSERT INTO public.chat_rooms (product_id, seller_id, buyer_id, status)
  VALUES (p_product_id, v_product.seller_id, v_top_bid.bidder_id, 'ACTIVE')
  ON CONFLICT (product_id) DO NOTHING;
END $$;
```

### 4.3 `close_expired_auctions()` — 마감 일괄 처리 (pg_cron용)

```sql
CREATE OR REPLACE FUNCTION public.close_expired_auctions()
RETURNS INTEGER
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
DECLARE
  v_count INTEGER := 0;
  r RECORD;
BEGIN
  FOR r IN
    SELECT id FROM public.products
    WHERE status = 'ON_SALE' AND end_time <= now()
    ORDER BY end_time
  LOOP
    BEGIN
      PERFORM public.close_auction(r.id);
      v_count := v_count + 1;
    EXCEPTION WHEN OTHERS THEN
      RAISE WARNING 'close_auction failed for %: %', r.id, SQLERRM;
    END;
  END LOOP;
  RETURN v_count;
END $$;

-- pg_cron 1분 간격
SELECT cron.schedule('close-expired-auctions', '* * * * *', $$ SELECT public.close_expired_auctions(); $$);
```

### 4.4 `confirm_trade(p_chat_id)` — 거래 완료 확정 (양쪽 모두 시 TRADED)

```sql
CREATE OR REPLACE FUNCTION public.confirm_trade(p_chat_id BIGINT)
RETURNS VOID
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_uid UUID := auth.uid();
  v_room public.chat_rooms;
  v_product public.products;
BEGIN
  IF v_uid IS NULL THEN
    RAISE EXCEPTION 'UNAUTHORIZED';
  END IF;

  SELECT * INTO v_room FROM public.chat_rooms WHERE id = p_chat_id FOR UPDATE;
  IF NOT FOUND THEN RAISE EXCEPTION 'CHATROOM_NOT_FOUND'; END IF;
  IF v_uid <> v_room.seller_id AND v_uid <> v_room.buyer_id THEN
    RAISE EXCEPTION 'CHAT_ACCESS_DENIED';
  END IF;

  SELECT * INTO v_product FROM public.products WHERE id = v_room.product_id FOR UPDATE;
  IF v_product.status <> 'ENDED' THEN
    RAISE EXCEPTION 'TRADE_NOT_AVAILABLE';
  END IF;

  IF v_uid = v_room.seller_id THEN
    IF v_room.seller_confirmed THEN RAISE EXCEPTION 'ALREADY_CONFIRMED'; END IF;
    UPDATE public.chat_rooms SET seller_confirmed = TRUE WHERE id = p_chat_id;
  ELSE
    IF v_room.buyer_confirmed THEN RAISE EXCEPTION 'ALREADY_CONFIRMED'; END IF;
    UPDATE public.chat_rooms SET buyer_confirmed = TRUE WHERE id = p_chat_id;
  END IF;

  -- 양쪽 모두 confirm 시 product TRADED
  IF EXISTS (
    SELECT 1 FROM public.chat_rooms
    WHERE id = p_chat_id AND seller_confirmed AND buyer_confirmed
  ) THEN
    UPDATE public.products SET status = 'TRADED' WHERE id = v_room.product_id;
  END IF;
END $$;
```

### 4.5 `delete_chat_room(p_chat_id)` — 채팅방 나가기 (양쪽 모두 시 완전 삭제)

```sql
CREATE OR REPLACE FUNCTION public.delete_chat_room(p_chat_id BIGINT)
RETURNS VOID
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_uid UUID := auth.uid();
  v_room public.chat_rooms;
BEGIN
  SELECT * INTO v_room FROM public.chat_rooms WHERE id = p_chat_id FOR UPDATE;
  IF NOT FOUND OR (v_uid <> v_room.seller_id AND v_uid <> v_room.buyer_id) THEN
    RAISE EXCEPTION 'CHAT_ACCESS_DENIED';
  END IF;

  IF v_uid = v_room.seller_id THEN
    UPDATE public.chat_rooms SET seller_deleted = TRUE WHERE id = p_chat_id;
  ELSE
    UPDATE public.chat_rooms SET buyer_deleted = TRUE WHERE id = p_chat_id;
  END IF;

  DELETE FROM public.chat_rooms
  WHERE id = p_chat_id AND seller_deleted AND buyer_deleted;
END $$;
```

## 7. 데이터 마이그레이션 정책

운영 데이터 없음 → **데이터 이관 0**. 신규 스키마에서 시작.
(개발 중 H2/MySQL 로컬 데이터는 필요 시 수동 INSERT 또는 시드 스크립트로 별도 처리)
